# Two-week drill

Follow this for ten working days. At the end you either do not want a dock, or you can say exactly which launch the dock was for.

The manual asks for two weeks. This page is those two weeks as homework. Each day has one new habit and keeps the previous ones. If you miss a day, repeat it. Do not stack three new habits to catch up.

Use the [work-day map](./from-overlapping-windows.md). Write the four workspace names on paper and keep the paper until day 14.

## Week one, the keys

**Day 1. The twelve.** Do the [drill](./twelve-keys.md) twice, morning and afternoon. Launch the terminal and the browser only with their keys. When you forget, `Super + K`, then do the chord. Looking it up is the method.

**Day 2. Focus and swap.** For every window you would have dragged, press `Super + Arrow` or `Super + Shift + Arrow` first. You may still drag with Super held. Say which key it would have been.

**Day 3. Retire the mouse for launching.** No dock, no desktop icon, no clicking a taskbar you do not have. `Super + Space`, type three letters, Enter. For the terminal, browser, files, and editor, use the direct keys. Count the times you reach for a mouse launch. The number should fall, not hit zero.

**Day 4. Close means quit.** `Super + W` all day. When an app is gone and you wanted it, open it again. Notice how often the old desktop was storing apps you were not using.

**Day 5. Workspaces 1 and 2 only.** Browser on 1, the thing you are making on 2. `Super + 1` and `Super + 2` are the whole day. Each time you try to put both on one workspace, ask if you truly need them visible together. If you do, leave them split for that task, then separate them when the task ends.

**Day 6. Send without following.** Once an hour, park a window with `Super + Shift + Alt + number`. Mail and chat live on 3 from this day on.

**Day 7. Name the four.** Fill in workspace 4. For most readers that is the agent, or the place a long job sits. If you do not use an agent, workspace 4 is the reference material. The scratchpad gets one glance-window today: `Super + Alt + S` to send it, `Super + S` to look.

## Week two, the judgment

**Day 8. Groups.** Take one real pile, three documents of the same task, and `Super + G` them. Live in that group for the morning. In the afternoon, take it apart with `Super + G` if it was the wrong pile.

**Day 9. Float on purpose.** Pick one window that should be a window, not a tile. A video, a small tool, a password prompt you already trust. `Super + T` or `Super + O`. Everything else stays tiled. If you float five things, you have rebuilt the old desktop and lost the ability to see them.

**Day 10. One scrolling workspace.** Put workspace 2 on scrolling with `Super + L`. Open the editor, a terminal, and the agent in a row. Work there for half a day. If `Super + J` errors, you are seeing the known limit: that key belongs to dwindle. Go back with `Super + L`, or stay and stop pressing J. At the end of the day, decide whether workspace 2 stays scrolling. One workspace is the experiment. Do not convert the machine.

**Day 11. Resize only when a tile is wrong.** Use `Super + Minus` and `Super + Equal` with the [directions in mind](./twelve-keys.md). Then try Super and the right mouse button. Most days you should resize nothing, because the layout already spent the pixels.

**Day 12. Capture and clipboard, the old reflexes.** Copy all day with `Super + C`, paste with `Super + V`, history with `Super + Ctrl + V`. Screenshot with `Print Screen`. Share one file with `Super + Ctrl + S` if you have another machine nearby. These are the gestures that make the old OS feel clumsy, so they belong in the hands before you judge the desktop.

**Day 13. A config, one line, on purpose.** Either natural scroll, or the three-finger gesture, from [the mouse page](./mouse-still-works.md). One change. Reboot or restart Hyprland the way that file tells you to, and live with it for the day. If you hate it, put the file back. *Update > Config* restores a shipped file you have mangled.

**Day 14. The dock decision.** Write two lists.

- Launches you still hunt for in the menu, more than twice a day.
- Windows you still wish were icons on a desktop.

If the first list is one or two apps, bind them, or accept `Super + Space` and three letters. If the second list is "I want to see everything," that is the overview Omarchy does not ship, and a dock will not draw it either. A dock that launches apps is a comfort plugin. The [plugins page](../../plugins/curated.md) will treat one as optional, after this drill, and will say out loud that third-party plugins run unsandboxed inside the shell.

People who finish day 14 and still want the dock should add one. People who add one on day 1 never learn the keys the dock is papering over.

## What done feels like

You open the terminal before you think about opening the terminal. You know which workspace the browser is on. You get annoyed when a window floats for no reason, and you press `Super + T` without looking it up. You use `Super + K` a few times a week for the long tail, and you do not apologize for that.

You will still lose a window sometimes. Send it home, or float it, and keep going.

## When this goes wrong

- You "fail" a day and redesign the keybindings. That resets the drill. Finish day 14 on the defaults, then change one key.
- You install a theme, a bar, and four plugins on day 2, and you can no longer tell a bug from a customization. Take the plugins off. The drill is about the stock desktop.
- Work requires two things on screen all day. That is allowed. See the monitor section on the [overlapping-windows page](./from-overlapping-windows.md). The drill is about the pile, not about pretending one screen is two.

Continue with [when it feels broken](./when-it-feels-broken.md).
