# How to read this

This is a field guide for Omarchy 4. Finish the switch and you can run the machine from the keyboard, keep a day's work in workspaces, and know which old habits to drop.

The [official manual](https://omarchy.org/manual/) documents every feature. These pages are the drills, the first-day mistakes, and the comparison with Windows and macOS. When a page and the manual disagree, believe the manual, then check `Super + K` on your own machine.

## What is already written

1. [Before you install](./00-before-you-install.md) covers the ISO, encryption, dual boot, and the snapshot limit.
2. [The first hour](./01-first-hour.md) is the first tiling session.
3. [The switch](./switch/mental-model.md) is seven pages: the model, the keys, a real workspace map, the mouse, translation tables, a two-week drill, and the errors that are not your fault.
4. [Ahead of other desktops](../advantages/index.md) names the features that are genuinely further along, and the gaps.
5. [The cheatsheet](../reference/cheatsheet.md) and [ten minutes with a friend](../reference/ten-minutes.md) are the short forms.

## What is still a stub

Daily driver, workflows, agents, plugins, and mastery are in the sidebar so the whole path is visible. Each one is marked **soon** and points at the manual chapter to use today. They are not lessons yet.

Agents are a first-class part of Omarchy 4. The practice pages for them are the next slice. Until those exist, the manual's [AI chapter](https://omarchy.org/manual/ai/) is the source, and the first-hour page tells you the one surprise: a launched agent acts, and a launch from your home directory starts in `~/Work`.

## The version this follows

Omarchy **4.0.4** and later, the Quattro line. Hyprland config is Lua under `~/.config/hypr/`. A tutorial that shows `bindd` lines in a `.conf` file is Omarchy 3. Press `Super + K` after any major update before you trust a printed card. The next announced release is Quattro RS 4.5. This guide does not describe 4.5 behavior ahead of the manual.
